Windows 微信红包本地助手 — 使用说明

一、开始前

1. 解压整个 WxRedHelper 文件夹；不要只复制其中的 WxRedHelper.exe。
2. 打开微信并登录。使用期间，微信窗口必须保持可见、位于前台且不能最小化。
3. 每台电脑、每个微信主题/缩放比例都必须重新采集模板，模板不会随安装包共享。

二、采集模板

双击 WxRedHelper.exe 后会显示操作菜单。选择任一采集项后，程序会倒计时，请在倒计时内切回微信窗口。

依次采集以下四个模板：

1. chat_header：在目标群聊普通聊天页，框选顶部群名称的稳定文字区域。
2. envelope_card：出现红包消息时，框选红包卡片的橙色主体区域。
3. open_button：手动点开红包后，框选圆形“开”按钮。
4. result：手动领取后，框选结果页中稳定、不与普通聊天重复的区域。

在菜单中依次选择 1、2、3、4 完成采集。选框会置于微信窗口最前方；拖动鼠标框选区域，按空格或 Enter 确认，按 Esc 或 C 取消。取消本次截图会保留已有模板并返回主菜单。

如需在终端中使用命令，也可分别运行：

WxRedHelper.exe collect-template chat_header --delay-seconds 5
WxRedHelper.exe collect-template envelope_card --delay-seconds 5
WxRedHelper.exe collect-template open_button --delay-seconds 5
WxRedHelper.exe collect-template result --delay-seconds 5

三、先测试再使用

先在菜单中选择 5（仅检测模式），确保终端提示“已检测到红包候选”时确实对应目标红包。确认稳定后，选择 6（自动领取模式）。

程序会先要求输入扫描间隔。请输入 30 到 80 之间的整数毫秒，例如 30、50 或 80；按 Enter 后再输入目标群聊名称，随后启动自动模式。数值越小，扫描越频繁。

调整扫描间隔只会改变轮询频率，不会取消群聊页头验证、两帧稳定识别、点击前窗口复核或异常页面中止机制。

菜单项 7 是“单次确认自动领取（固定 50ms）”：不需要输入扫描间隔，输入目标群聊名称后即开始。此模式中，每个页面目标在一张截图中识别到即可进入原有领取流程，因此比普通自动模式更快，但误匹配风险更高；只建议在模板、缩放比例和微信主题均已通过仅检测模式验证后使用。

单次确认模式仍保留识别置信度、群聊页头验证、红包卡片→“开”按钮→结果页的页面顺序，以及点击前窗口复核。它不会只截一张图后停止，而是每 50ms 持续扫描。

如需使用命令行，普通检测模式为：

WxRedHelper.exe run --mode detect --allow-title "目标群聊"

确认稳定后，才运行自动模式。扫描间隔必须是 30 到 80 的整数毫秒：

WxRedHelper.exe run --mode auto --allow-title "目标群聊" --interval-ms 50

单次确认自动领取模式固定使用 50ms：

WxRedHelper.exe run --mode single --allow-title "目标群聊"

按 Ctrl+C 可停止程序。若窗口切换、窗口最小化、识别不确定或页面异常，程序会中止本轮而不继续点击。

四、隐私与限制

工具只处理可见的微信客户区图像，不读取聊天数据库、进程内存或网络通信。它不处理验证码、风控提示、后台窗口或未知页面。
